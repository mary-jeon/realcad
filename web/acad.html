예제 부품 / Examples: 사진 보고 18개 중 골라 바로 만들기 (명령 EX) / Pick one of 18 and make it right away (EX)
가져오기 / Import: 내 STL, STEP 파일을 올려 맞는 케이스를 만들거나 나눠서 뽑기 / Upload your STL or STEP to build a case or split it
스케치 / Sketch: SK, L 선, C 원, REC 사각형, A 호, POL 다각형, TR 자르기, O 오프셋, DIM 치수, 돌출은 EXT / SK, L line, C circle, REC rectangle, A arc, POL polygon, TR trim, O offset, DIM dimension, EXT extrude
명령창 / Command line: 스페이스나 Enter 로 실행, 빈 칸에서 스페이스는 마지막 명령 다시, 파란 [옵션]은 눌러도 돼요, Esc 취소 / Space or Enter runs it, Space on an empty line repeats, blue options are clickable, Esc cancels
보기 / View: 위 가운데 방향, 표시, 투명도, 아래 가운데 전체 보기(Z), 회전, 확대 / Top center: view, look, opacity. Bottom center: zoom extents (Z), orbit, zoom
상태 줄 / Status bar: F7 격자, F9 스냅, F3 객체 스냅, F8 직교, Ctrl+0 패널 숨기기 / F7 grid, F9 snap, F3 object snap, F8 ortho, Ctrl+0 clean screen
검사, 내려받기 / Checks, download: 만들면 바로 19가지 검사, 통과하면 초록 단추로 파일 받기, 다른 형식은 옆 ▾ / 19 checks run right away, the green button downloads, other formats under ▾
되돌리기 / Back: ↩ 이전으로, 명령 U, 스케치 안에서는 Ctrl+Z / ↩ Back, U, or Ctrl+Z in a sketch
