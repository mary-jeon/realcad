# 상용 제품 규격 조회 단계: 근거와 결정표 (2026-10-31)

"맥미니를 거는 브래킷" 처럼 시판 제품 이름이 들어오면 치수를 모델이 지어내지 않고,
공식 규격표 → Meta 기억(확신도) → 사용자 실측 순으로 채운다. 아래는 그 설계의 근거다.

## 1. Meta 모델 기억 실측 (muse-spark-1.3, temperature 0, 2026-10-31)

| 제품 | 모델 답 (mm, g) | 공식 스펙 | 모델 자기 확신도 | 판정 |
|---|---|---|---|---|
| Apple Mac mini M4 2024 | 127 x 127 x 50, 670 | 127 x 127 x 50, 670 | 0.98 | 일치 |
| Apple MacBook Air 13 M3 | 304.1 x 215 x 11.3, 1240 | 304.1 x 215 x 11.3, 1240 | 0.98 | 일치 |
| Nintendo Switch OLED | 242 x 102 x 13.9, 422 | 242 x 102 x 13.9, 약 420 | 0.9 | 일치 |
| Raspberry Pi 5 | 85 x 56 x 17, 52 | 보드 85 x 56, 무게 약 46 | 0.6 | 보드 치수 일치, 높이와 무게는 흔들림 |
| Twelve South Curve | 267 x 222 x 146 | 확인 필요 | 0.5 | 보류 |

읽는 법: 확신도가 0.9 이상이면 mm 단위까지 맞았고, 0.6 근처부터 보조 치수가 흔들린다.
그래서 상태 기준을 0.9 / 0.6 두 개로 잡았다. 모델이 적어준 출처 URL 은 기억에서 꺼낸 것이라
그대로 표시하지 않고, 공식 규격표에 있는 제품만 출처를 보여준다.

## 3. 브래킷 설계 관행 (기존 공개 모델에서 가져온 결정)

| 결정 | 값 | 근거 |
|---|---|---|
| 포켓 여유 | 제품 + 0.2 mm/변 (보통 끼움) | codegen 의 기존 CLEARANCE 규칙, MakerWorld 수직 거치대의 "tight / 1.5 mm 여유" 두 버전 관행 |
| 바닥 | 막대 3개, 전체 막지 않음 | 바닥 흡배기(위 2절), MakerWorld 수직 스탠드의 "흡기 원형 구멍에 맞춘 세로 슬롯 5개" |
| 뒷면과 앞면 | 열어 둠, 케이블 여유 60 mm | 뒤 포트 5개와 전원 코드, Newegg VESA 브래킷 경고(포트 막힘) |
| 벽 두께 | 3 mm | 공개 모델 프로필이 2~4 벽(0.4 노즐, 0.8~1.6 mm) + 15% 채움이라 강성 여유로 3 mm |
| 전원 버튼 | 바닥 뒤 모서리 열어 둠 | 사례 모델의 Ø10 구멍 |
| 상대편 물건 치수 | 모델에게 묻지 않고 사용자 실측 | 거치대 팔 폭과 두께는 제품마다 달라 어떤 모델도 모름 (Twelve South Curve 확신도 0.5) |

## 4. 되묻는 질문의 원칙

모델이 아는 것(공식 치수, 벽 두께, 끼움 여유)은 묻지 않는다. 묻는 것은 세 가지뿐이다:
상대편 물건의 폭과 두께, 제품을 어느 방향으로 둘지, 어디에 붙일지. 최대 3개, 중요한 순서.
실측 예(2026-10-31, 맥미니 + 노트북 거치대 팔): "팔 너비", "팔 두께", "세로로 세울 때 후면 포트 방향" 세 개가 나왔다.
